# 학기 프로젝트

## 프로젝트 소개

현재 주제는 **1인칭 경쟁 FPS 게임에서의 피커스 어드밴티지(Peeker's Advantage)**에 대해 공부하고, 서버와 사용자 간의 상호작용 및 네트워크 구조를 알아보는 것입니다.

온라인 게임에서는 사용자의 행동이 클라이언트에 입력되고 네트워크를 통해 서버로 전달되는 과정이 필요합니다. 이 과정에서 **Ping, 패킷 전달, 서버 처리 등의 차이**가 발생하며, FPS 게임에서는 이러한 지연으로 인해 먼저 움직이는 플레이어가 상대보다 유리해지는 피커스 어드밴티지가 발생할 수 있습니다.

인터넷 통신의 특성상 이를 완전히 제거하기는 어렵지만, 관련 요소를 분석하고 **피커스 어드밴티지를 완화할 수 있는 방법을 알아보는 것**을 목표로 프로젝트를 진행할 예정입니다.


## 만들고 싶은 이유

평소 인터넷 게임을 좋아하기에 자연스럽게 피커스 어드벤티지라는 단어를 접하게 되었으며 프로젝트 선정을 하게 되었습니다.
또한 이 문제를 완화시키는 공부를 하면서 여러 공부에 도움이 될거같았습니다.
